# Medikto Marketing Website

This directory contains the public-facing marketing website for **Medikto**, built using **Next.js 15 (App Router)**, **TypeScript**, and **Tailwind CSS**.

## Features
- **Patient-Centric Health Telemetry**: Highlights medication scheduling, live vitals tracking, encrypted document locker, and caregiver connectivity.
- **Brand Identity**: Features official Medikto brand logo (`medikto_logo.png`, `medikto_icon.png`, `favicon.svg`).
- **Interactive Demos & Modals**: Complete interactive preview tour, prescription setup, vitals logging, document vault scanner, doctor PDF report generator, and senior usability accessibility toggle.
- **SEO & Performance Optimization**: Next.js Metadata API, JSON-LD structured data (`MedicalWebPage`), OpenGraph, Twitter Cards, `robots.ts`, and `sitemap.ts`.

## Getting Started

### Prerequisites
- Node.js 18+ or Node.js 20+

### Installation & Local Development

```bash
cd website
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm run start
```
